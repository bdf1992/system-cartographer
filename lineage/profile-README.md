## Brandon Freeman

Worldbuilder. Then somebody handed me programming, AI and a product job, and
this is what happened.

Worlds break quietly. A note contradicts an older note. A word you defined once
has drifted into meaning two things and nothing told you. The fix is
unglamorous. Name things carefully, keep the history, know who changed what. It
took me an embarrassingly long time to notice that is also the job I have been
paid to do for nine years.

[Soveraeign](https://github.com/bdf1992/Soveraeign) is the big one. People and models on the same records, the same
permissions, the same history, no private door for either. [ontum](https://github.com/bdf1992/ontum) takes that
into work a model does alone: the log is the truth and every other view is folded
out of it. Before it was [onton](https://github.com/bdf1992/onton), archived now, which recorded how a thing was
made so whoever got it next could tell.

A drawing of a schematic is a picture of one. [schematically](https://github.com/bdf1992/schematically) keeps the model
underneath instead, with real components, parts and wires, written in
Soveraeign's format. It replaced [Canvas](https://github.com/bdf1992/Canvas), and [ide](https://github.com/bdf1992/ide) is a small editor that
opens in a chat panel.

A lot of the rest is harness work: the skills, roles and rules a model runs
under. [familiar](https://github.com/bdf1992/familiar) holds agent guidance a practitioner has to accept before it
binds.
[Owl](https://github.com/bdf1992/Owl) takes a rough ask, builds the whole clumsy thing early, then redraws that
same thing from feedback instead of quietly starting a different project.
[HowDo](https://github.com/bdf1992/HowDo) is what both of those assume.

[context](https://github.com/bdf1992/context) is one file you drop into a directory to give an agent a bounded
world. [system-cartographer](https://github.com/bdf1992/system-cartographer) runs the other
way, from a working agent system back to the description nobody ever wrote.
[DDD-CCC](https://github.com/bdf1992/DDD-CCC) asks what your tests actually cover, meaning-wise, and says where the
holes are.

I do this at work too. A workflow engine with retrieval over company knowledge,
running long jobs with a person at every decision. A state machine, not an
open-ended agent, so you can audit it and back it out. You'll have to take my
word for that one.

[small-world](https://github.com/bdf1992/small-world) is a lab for generative worlds. [nostalgia](https://github.com/bdf1992/nostalgia) gets old games running
and playable with friends again. Those count as much as the rest.

All of it is checked, and [the record](https://github.com/bdf1992/system-cartographer/blob/claude/access-requirements-zbl1s7/lineage/lineage.yaml) has the commands, what they returned, how
these connect, and which ones connect to nothing at all.

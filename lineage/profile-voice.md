## Brandon Freeman

Worldbuilder. Most of the rest of this came out of that.

Keep a world going long enough and you hit the boring problems. Two notes
disagree. A name starts meaning two things. Somebody changed a rule and nobody
wrote down that they did. Fixing that is metadata, taxonomy, versioning and
access control — which is also, it turns out, nine years of my day job.

So most of what follows is one question in different clothes. When a claim
carries the evidence for it, two parties can hold the same state instead of each
keeping a copy with a separate account of it, and they end up in one frame rather
than two. That works between people. Whether it works between a person and a
model is what I'm actually testing.

**Records.** {soveraeign} is the long version: people and models working through
the same records, permissions and history, neither getting a private door
({soveraeign.check}). {ontum} points the same instinct at autonomous work — an
append-only log is the truth and every other view is folded from it
({ontum.check}). It grew out of {onton}, archived now, which typed how an
artifact was made so that trust survived being handed on.

**Making.** {schematically} treats a schematic as a semantic model of components,
parts and wires rather than a drawing, and writes it in Soveraeign's document
format ({schematically.check}). It superseded {canvas}, which was the same idea
about arranging things in space. {ide} is a small editor that opens in a chat
side panel.

**Models.** {familiar} is a workbench for agent guidance that a practitioner has
to accept before it binds ({familiar.check}). It uses {owl}, which turns a rough
ask into a complete inspectable attempt and then redraws that same target from
feedback instead of wandering onto a different one. {howdo} is the discipline
under both — understand the problem before acting on it ({howdo.check}).
{ddd-ccc} asks how much of a repository's meaning its tests actually reach, and
names the gaps.

**Fun.** {small-world} is a lab for generative worlds ({small-world.check}).
{nostalgia} gets old games running and playable with friends again. Those aren't
the side quests.

Every claim above names a command you can run and what it returned on {observed}.
{total} tests pass across {contributors} of the {repos} repositories; the rest
count in suites, checks and proofs, which are real but not the same unit, so I
don't add them together. {lineage} holds all of it — what is archived, the
{unconnected} that connect to nothing, the {edges} relations between them with
the file and line that shows each one, and the ones I looked for and could not
evidence.

## Brandon Freeman

Worldbuilder. Most of the rest of this came out of that.

A world you keep working on starts contradicting itself. Two notes disagree; a
name has started meaning two things. Fixing that is metadata, taxonomy,
versioning and access control — which is also nine years of my day job.

So most of what follows asks one question. When a claim carries the evidence for
it, two people can work in one frame instead of each holding a copy and a
separate account of it. That works between people. Whether it works between a
person and a model is what I'm testing.

**Records.** {soveraeign} puts people and models on the same records, the same
permissions and the same history, with no private door for either. {ontum}
narrows that to autonomous work: an append-only log is the truth, and every other
view is folded from it. It grew out of {onton}, archived now, which recorded how
an artifact was made so the next person could tell.

**Making.** {schematically} treats a schematic as a semantic model of components,
parts and wires rather than a drawing, and writes it in Soveraeign's document
format. It superseded {canvas}, which arranged things in space the same way.
{ide} is a small editor that opens in a chat side panel.

**Working with models.** Most of this is harness work — the skills, roles and
rules a model runs under. {familiar} holds agent guidance that a practitioner has
to accept before it binds. It uses {owl}, which turns a rough ask into a complete
inspectable attempt, then redraws that same target from feedback instead of
wandering onto a different one. {howdo} is what both assume: understand the
problem before acting on it. {context} hands an agent a bounded world in a single
file. {system-cartographer} works backwards from a running agent system to the
description nobody wrote. {ddd-ccc} asks how much of a repository's meaning its
tests actually reach.

I do this at work too: a workflow engine with retrieval over company knowledge,
running multi-step jobs with a person at every decision point. A state machine
rather than an open-ended agent, so every step can be audited and rewound. That
one you can't check from here.

**Fun.** {small-world} is a lab for generative worlds. {nostalgia} gets old games
running and playable with friends again. Those aren't the side quests.

All of it is checked, and {lineage} carries the command for each repository and what it
returned, how they relate with the file and line that shows it, and the ones that
connect to nothing.
